# FastRead

Читалка в стиле RSVP / Spritz: слова по одному появляются в центре экрана, и каждое выравнивается по красной фокусной букве. Взгляд стоит на месте, текст сам идёт к глазам. Двуязычные режимы помогают учить язык прямо во время чтения.

## Запуск

Открой `index.html` в браузере. Ни сборки, ни сервера не нужно.

## Чтение

- **Фокусная буква**: средняя (при чётной длине левая из двух средних) или «чуть левее», как в Spritz. Пунктуация в длину слова не входит.
- **Пунктуация держится за слово**: `слово,`, `«Кто-то»`, `— Привет`, `Москва —`.
- **Умные паузы** на запятых, точках, абзацах, длинных словах и числах.
- **Длинные слова** делятся по слогам: `Достопри- мечатель- ность`.
- **Перемотка**: на слово, на 10 слов, по предложениям, ползунком. На паузе показывается кусок текста, клик по слову переносит к нему.
- **Файлы**: `.txt`, `.md`, `.fb2`, `.epub`, `.html` (кодировка windows-1251 определяется сама) и `.json` — двуязычные паки.
- **Библиотека** запоминает тексты и позицию в каждом (IndexedDB в браузере).

## Двуязычные режимы

Работают для **паков**: JSON, где у каждого слова есть контекстный перевод, а у каждого предложения — перевод целиком. Два примера встроены, они открываются в «+ Текст».

| Режим | Что происходит |
|---|---|
| **Перевод под словом** | под каждым словом полупрозрачный перевод (прозрачность настраивается) |
| **Подсказки с задержкой** | перевод проявляется через ~300 мс и только у слов выбранного уровня (A1–C2): сначала попробуй понять сам |
| **Перевод предложений** | читаешь предложение потоком, после точки на мгновение виден его перевод |
| **Вкрапления** | русский текст, часть слов заменена английскими (подсвечены синим); плотность 1–5 |
| *Без перевода* | только текст; на паузе перевод текущего слова всё равно виден |

Работает с текстом в обе стороны: английский с русскими подсказками или русский с английскими (`lang` / `gloss_lang` в паке).

**Колода «не знаю».** Во время чтения жми `D` (или закладку внизу справа), и слово попадёт в колоду: начальная форма, словарный перевод, предложение и его перевод. «Слова» в шапке открывают повторение карточек с интервалами (10 мин → 1 → 3 → 7 → 16 → 35 → 90 дней) и экспорт в CSV для Anki. Колода работает и с обычными текстами, только перевод там пустой.

## Как сделать свой пак

1. Дай LLM-агенту промпт из [`agents/PACK_PROMPT.md`](agents/PACK_PROMPT.md) и текст: язык текста, язык переводов, какой учишь.
2. Проверь результат:
   ```bash
   python3 tools/validate_pack.py my-pack.json
   ```
   Длинную книгу проще размечать частями и склеить:
   ```bash
   python3 tools/validate_pack.py --merge book.json part1.json part2.json part3.json
   ```
3. Загрузи `.json` через «+ Текст» (или просто вставь JSON в поле текста).

Новые примеры кладутся в `examples/`, а затем `python3 tools/embed_examples.py` встраивает их в `index.html`: браузер не даёт странице, открытой с диска, читать соседние файлы.

## Клавиши

| | |
|---|---|
| `Пробел` | старт / пауза |
| `←` `→` | ± 1 слово (с `Shift` ± 10) |
| `[` `]` | предыдущее / следующее предложение |
| `↑` `↓` | скорость ± 25 слов/мин |
| `D` | «не знаю» — слово в колоду |
| `M` | следующий режим перевода |
| `Home` | в начало |
| `N` / `L` / `W` | новый текст / библиотека / слова |
| в повторении: `Пробел`, `1`, `2` | показать / не помню / помню |

## Структура

```
index.html                  приложение целиком (HTML+CSS+JS, примеры встроены)
examples/                   двуязычные паки-примеры
agents/PACK_PROMPT.md       промпт для агентов, которые размечают тексты
tools/validate_pack.py      проверка и склейка паков (stdlib Python)
tools/embed_examples.py     встраивает examples/*.json в index.html
```

## Примечания

- EPUB распаковывается библиотекой JSZip с CDN, поэтому для EPUB нужен интернет. Остальное работает офлайн.
- Примеры: O. Henry, «The Gift of the Magi» (1905), и А. П. Чехов, «Хамелеон» (1884). Оба текста — общественное достояние.
